# Methodology

## 1. Sample Collection

- **Sample Type:** Plastic-polluted coastal sediment
- **Location:** Mayiladuthurai, Tamil Nadu, India
- **Sampling Depth:** 5–10 cm

---

## 2. DNA Extraction

Genomic DNA was extracted using the **Beaver Beads Nucleic Acid Extraction Kit** following the manufacturer's protocol.

---

## 3. Library Preparation and Sequencing

- **Sequencing Platform:** Illumina NovaSeq 6000
- **Library Preparation Kit:** Nextera XT DNA Library Preparation Kit
- **Sequencing Strategy:** Paired-end sequencing
- **Read Length:** 2 × 150 bp

---

# Bioinformatics Workflow

## 4. Sequencing Quality Assessment

Raw sequencing reads were assessed using **FastQC** to evaluate sequencing quality, GC content, adapter contamination, and base quality scores.

---

## 5. Read Filtering and Trimming

Low-quality bases and sequencing adapters were removed using **fastp**, producing high-quality reads for downstream analyses.

---

## 6. Metagenome Assembly

Filtered reads were assembled into contigs using **MEGAHIT**, a de novo assembler optimized for metagenomic datasets.

Assembly quality was evaluated using **QUAST**.

---

## 7. Taxonomic Profiling

Quality-filtered reads were taxonomically classified using:

- Kraken2
- Bracken

to estimate microbial community composition and relative abundance.

---

## 8. Coverage Estimation

Reads were mapped back to assembled contigs using **Bowtie2** to estimate contig coverage for genome binning.

---

## 9. Genome Binning

Metagenome-assembled genomes (MAGs) were reconstructed independently using:

- MetaBAT2
- MaxBin2
- CONCOCT

---

## 10. Bin Refinement

MAGs generated by the three binning algorithms were integrated and refined using **DAS Tool**.

---

## 11. MAG Quality Assessment

Genome completeness and contamination were assessed using **CheckM2**.

---

## 12. Genome Annotation

Protein-coding genes were predicted and annotated using **Prokka**.

---

## 13. Functional Annotation

Functional annotation was performed using **eggNOG-mapper** to assign:

- Gene Ontology (GO)
- COG functional categories
- KEGG Orthology (KO)

---

## 14. Taxonomic Classification of MAGs

Recovered MAGs were taxonomically classified using **GTDB-Tk (Release R232)**.

---

## 15. Protein Domain Analysis

Predicted proteins were analyzed using **InterProScan** to identify conserved domains and functional signatures.

---

## 16. KEGG Pathway Reconstruction

KEGG Orthology assignments obtained from eggNOG-mapper were used to reconstruct metabolic pathways.

---

## 17. Identification of Candidate Plastic-Degrading Enzymes

Candidate plastic-degrading enzymes were identified by integrating:

- Prokka annotations
- eggNOG functional assignments
- InterPro protein domain predictions

The identified proteins represent **computational predictions** requiring experimental validation.
