# InterProScan Analysis

Protein sequences predicted by Prokka were submitted to the InterPro web server for protein domain analysis.

Input:
- prokka_output/bin3/bin3.faa
- prokka_output/maxbin002/maxbin002.faa

Analyses performed:
- Conserved protein domain identification
- Protein family assignment
- Functional signature prediction

The resulting annotations were integrated with eggNOG-mapper functional assignments to identify candidate proteins potentially associated with plastic degradation.
